# Content helpers

Reusable tools for importing researched content into a market:
`apply_beaches.py`, `apply_intros.py`, `apply_verdict_batch.py`, `apply_faq_batch.py` (JSON batches),
`photo_sync.py` (own photos → Cloudinary → island JSON), `audit-coordinates.py` (OSM coordinate check).
Run from the repo root, e.g. `python3 tools/content/apply_intros.py batch.json`.
